# House Rules — пиксельный свиток

Свиток с правилами, который открывается по обычной ссылке. Внизу две печати. Каждый ставит свою со своего телефона: открывает форму, придумывает и вводит своё секретное слово — то, что введёшь первым, и становится твоим секретным словом навсегда, второй человек его не видит ни на странице, ни в коде, ни в репозитории. Когда стоят обе печати, свиток пишет «In force since…».

Как это устроено:

- **Сайт** — статичные файлы на GitHub Pages.
- **Печати** хранятся в `seals.json`, хэши секретных слов — в `words.json`, оба файла в этом же репозитории. Каждая поставленная печать и каждое заданное слово — отдельный коммит.
- **Сервис печатей** — маленькая функция в Yandex Cloud: при первом слове для печати запоминает его хэш, при всех следующих — сверяет с ним, и если верно, записывает печать в `seals.json` через GitHub API. Само слово нигде не сохраняется, ни в каком виде, только его хэш (его нельзя обратить назад в слово). Yandex выбран потому, что Cloudflare и сервисы за ним (Supabase и т. п.) из России сейчас работают нестабильно.

```
index.html            свиток
config.js             адрес сервиса печатей (вставить после шага 3)
seals.json            печати; null = не поставлена
words.json            хэши секретных слов; появляется сам при первой печати
assets/               стиль «Свиток»: svitok.css, svitok.js, шрифты, иконка вкладки
assets/house-rules.js логика печатей на странице
assets/ceremony.js    финал, окно-артефакт и календарь правления
assets/ceremony.css   стили для них
assets/heroes.js       два пиксельных героя под печатями
assets/landscape.js    пиксельный пейзаж за свитком: небо, облака, горы, лес
assets/landscape.css   стили для него
assets/rollup.js       свернуть и развернуть свиток
backend/index.py      сервис печатей (Yandex Cloud Function, Python 3.12, без зависимостей)
dev_server.py         всё вместе локально
tests/                pytest для сервиса печатей
```

## Перед началом

Репозиторий для GitHub Pages на бесплатном плане должен быть **публичным**. Значит, текст правил будет виден всем, кто найдёт репозиторий или сайт. Секретные слова при этом нигде не хранятся, только их хэши — и те появляются лишь после того, как кто-то реально нажмёт свою печать. Если правила должны остаться приватными, нужен GitHub Pro (Pages из приватного репозитория) или другой хостинг.

## 1. Репозиторий и GitHub Pages

```bash
cd house-rules
git init -b main
git add .
git commit -m "House Rules"
git remote add origin https://github.com/<ваш-ник>/house-rules.git
git push -u origin main
```

Сначала создайте пустой публичный репозиторий `house-rules` на github.com, потом выполните команды.

Дальше на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**. Через минуту-две свиток откроется по адресу `https://<ваш-ник>.github.io/house-rules/`. Печати пока только для чтения.

## 2. Токен GitHub для сервиса печатей

**github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:

- **Repository access:** Only select repositories → `house-rules`;
- **Permissions → Repository permissions → Contents:** Read and write;
- **Expiration:** на ваш вкус. Когда срок истечёт, печати перестанут ставиться, и токен нужно будет перевыпустить.

Скопируйте токен (`github_pat_…`). Он нужен только функции, в сайт его не вставляйте.

## 3. Функция в Yandex Cloud

1. Зайдите в [console.yandex.cloud](https://console.yandex.cloud). Для бесплатного объёма нужен платёжный аккаунт. Бесплатно — 1 000 000 вызовов в месяц, свиток израсходует единицы.
2. **Cloud Functions → Создать функцию**, имя `house-rules-seals`.
3. **Редактор → Python 3.12 → Способ: редактор кода**. Создайте файл `index.py` и вставьте содержимое `backend/index.py`.
4. Параметры:
   - **Точка входа:** `index.handler`
   - **Таймаут:** 10 секунд
   - **Память:** 128 МБ
   - **Переменные окружения:**

| Переменная | Значение |
| --- | --- |
| `GITHUB_TOKEN` | токен из шага 2 |
| `GITHUB_REPO` | `<ваш-ник>/house-rules` |
| `GITHUB_BRANCH` | `main` |
| `SEAL_SALT` | любая случайная строка, не секрет — например, вывод `python3 -c "import os; print(os.urandom(16).hex())"` |
| `ALLOWED_ORIGIN` | `https://<ваш-ник>.github.io` |

5. **Сохранить изменения** (создаётся версия).
6. На странице функции, в «Обзоре», включите **Публичная функция** и скопируйте ссылку вида `https://functions.yandexcloud.net/d4e…`.

Проверка: откройте эту ссылку в браузере. Должно показать `{"seals": {"ruslan": null, "wonder": null}}`.

Токен надёжнее положить в Yandex Lockbox и подключить к функции как секрет. Для двух печатей хватит и обычной переменной.

## 4. Включить печати на сайте

Вставьте ссылку на функцию в `config.js`:

```js
window.HOUSE_RULES_CONFIG = {
  api: "https://functions.yandexcloud.net/d4e…"
};
```

Затем:

```bash
git commit -am "Connect the seal service"
git push
```

Через минуту откройте сайт, нажмите на свою печать и впервые введите своё слово — оно само станет вашим секретным словом, печать встанет сразу. Ссылку отправьте второй стороне: она точно так же нажимает свою печать и вводит своё слово, вы его не увидите — ни на странице, ни в репозитории, нигде. Страница проверяет печати раз в 20 секунд, так что вторая печать появится у вас сама.

## Если что-то пошло не так

- **«That's not the secret word».** Для этой печати слово уже зарегистрировано (кто-то его один раз ввёл раньше) и введённое не совпадает. Слово нельзя посмотреть или восстановить — можно только сбросить и ввести заново (см. «Сменить секретное слово» ниже).
- **«The seal service didn't answer».** Посмотрите **Логи** функции в Yandex Cloud. Чаще всего причина — неверный `GITHUB_REPO` или токен без доступа Contents: Read and write.
- **Сменить секретное слово.** Откройте `words.json` в репозитории на GitHub (появляется после первой печати), замените нужное значение на `null` и закоммитьте. Следующее слово, введённое в эту печать, станет новым секретным словом.
- **Снять печать.** Откройте `seals.json` в репозитории на GitHub, замените значение на `null` и закоммитьте. Со страницы печать не снимается, так и задумано.
- **Изменить правила.** Правьте текст в `index.html` и пушьте.

## Финал, артефакт и календарь

Когда стоят обе печати, страница устраивает церемонию: печати вспыхивают, свиток вздрагивает, сверху вылетает пиксельное конфетти, выезжает баннер «Rules ratified» и играет короткая фанфара. Затем открывается окно «Artifact acquired». Под печатями появляется календарь: Month / Week / Day от даты «In force since» и название недели с её эффектом. Всё это работает в браузере, сервис печатей не нужен.

- Церемония играет один раз на устройство (это запоминается в браузере). Кнопки под календарём: **Artifact** открывает окно снова, **Replay** повторяет церемонию, **Sound** включает и выключает фанфару. В приватном режиме браузера церемония будет играть при каждом открытии.
- Если печать поставили на другом телефоне, церемония запустится сама, когда страница это увидит (до 20 секунд). Звук браузеры разрешают только после касания страницы, поэтому у второго человека фанфара может промолчать, пока он не коснётся экрана. На iPhone звука не будет при включённом беззвучном режиме.
- При включённом в системе «уменьшить движение» вспышки, тряска и конфетти отключаются.
- Недели календаря и их эффекты: массив `WEEKS` в начале `assets/ceremony.js`. Их двенадцать, потом они идут по кругу.
- Текст и бонусы окна-артефакта: блок `<dialog id="artifact">` в `index.html`.
- Мелодия фанфары: массивы `LEAD`, `HARMONY` и `BASS` в `assets/ceremony.js` (частота ноты, начало и длина в секундах).
- Под печатями стоят два пиксельных героя: рыцарь и принцесса. После церемонии, когда окно-артефакт закрыто, они идут друг к другу, встречаются, и над ними появляется сердце. При следующих заходах они уже стоят вместе. Клик по героям заставляет их подпрыгнуть. Рисунки лежат в `assets/heroes.js` строками из букв, рядом палитра: поменяв цвет в палитре (`h` и `H` для волос, `t` и `T` для туники, `d`, `D` и `u` для платья), меняете волосы и одежду. Строки можно править как пиксельную графику.
- В шрифте Pixelify Sans отключены лигатуры: сочетания «fi», «ff» и «fl» в нём рисовались криво («flexible», «classified»).

## Пейзаж за свитком

За свитком нарисован пиксельный пейзаж: небо с плывущими облаками, горы и лес. Небо меняется по часам на устройстве того, кто смотрит: рассвет с 5:00 до 8:00, день с 8:00 до 17:00, закат с 17:00 до 21:00, ночь с 21:00 до 5:00. Ночью мерцают звёзды и светит луна. Страница проверяет время раз в минуту и сама перерисовывает небо.

- Посмотреть конкретное время суток можно по адресу с `?sky=dawn`, `?sky=day`, `?sky=sunset` или `?sky=night`, например `https://rusnikolaenko.github.io/house-rules/?sky=night`.
- Цвета для каждого времени суток лежат в `PHASES` в начале `assets/landscape.js`: небо сверху вниз, горы, лес, облака, солнце или луна.
- Горы и деревья строятся из фиксированного зерна, так что пейзаж одинаковый при каждом заходе.
- Времена года идут по дате: весна с марта по май, лето с июня по август, осень с сентября по ноябрь, зима с декабря по февраль. Среди елей растут лиственные деревья: весной они цветут и летят лепестки, летом зелёные, а ночью над лесом мигают светлячки, осенью рыжие и жёлтые, падают листья, зимой стоят голые, всё в снегу, идёт снег. Посмотреть любое время года можно по адресу с `?season=spring`, `?season=summer`, `?season=autumn` или `?season=winter`, его можно сочетать с `?sky=`, например `?season=winter&sky=night`. Цвета времён года лежат в `SEASONS` в `assets/landscape.js`.
- Днём, на рассвете и на закате иногда пролетает стая птиц. Ночью падают звёзды: если успеть кликнуть по небу рядом с падающей звездой, появится «Wish made» и рассыплются искры.
- При включённом в системе «уменьшить движение» облака стоят на месте, звёзды не мерцают, а падающих листьев, снега, птиц и падающих звёзд нет.

## Свернуть свиток

Кнопка **Roll up** в правом нижнем углу сворачивает свиток: он скатывается, страница прокручивается вверх, и свёрнутый свиток, перевязанный лентой с восковой печатью, висит над пейзажем. Развернуть его можно кнопкой **Unroll**, кликом по печати или по самому свитку. Если в это время поставят вторую печать, церемония развернёт свиток сама. На телефоне вместо кнопки с надписью показывается только значок.

## Локально

```bash
python3 dev_server.py        # http://localhost:8000, слово для каждой печати — любое, вводите при первом нажатии
pip install pytest && python3 -m pytest -q
```

Локальный сервер хранит печати в `seals.local.json`, хэши слов — в `words.local.json`; оба в git не попадают.
